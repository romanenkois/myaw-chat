# Myaw chat main repository

This repo links all the used repositories of myaw chat services, libs and tools, as well with the docker setup.

## Repositories

### Public

- [**myaw-frontend**](https://github.com/romanenkois/myaw-frontend) - Frontend Angular Nx monorepo
- [**myaw-cli**](https://github.com/romanenkois/myaw-cli) - CLI tool for managing myaw services

### Private

- **myaw-backend** - Main backend service, used as an REST API
- **myaw-realtime** - Realtime backend service, used for WebSocket connections
- **myaw-ui** - Perspective custom UI library, that is planned to be separated from main frontend monorepo
